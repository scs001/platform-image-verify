# legalskill-legal-consultation

## What this is

为律师、法务提供法条检索、法规查询、案例研究、判例检索、指导案例查找、司法解释解读、合同审查与专业研判，为普通公众提供法律咨询、案件分析和维权指导。适用于普通用户描述日常纠纷、追问法律后果或寻求行动策略，即使用户未使用法律术语，常见说法如欠钱不还、被起诉、打官司、合同违约、离婚、抚养权、抚养费、探视权、家暴、彩礼、遗产继承、劳动纠纷、工伤、加班费、年终奖、竞业限制、违法解除、违法辞退、裁员、被辞退、经济补偿、年休假、交通事故、车祸、租房押金不退、消费者投诉、公司股权争议、合伙纠纷、股权代持、股东知情权、拆迁补偿、行政处罚、行政复议、知识产权侵权、商标侵权、专利纠纷、著作权纠纷、商业秘密、不正当竞争、房屋买卖纠纷、物业纠纷、邻里纠纷、名誉权侵权、隐私泄露、网络暴力、医疗事故、医疗纠纷、保险合同纠纷、人身损害、被人打了、食品安全、产品责任等，或问"怎么办""能不能告""会不会坐牢""能赔多少""胜算大吗""有什么风险""要赔多少钱""会不会被拘留""会不会判刑""能不能缓刑""怎么应诉""如何反诉""如何上诉""打官司要多久""证据不足怎么办""对方不履行怎么办""律师费多少""仲裁和诉讼哪个好""要不要请律师""自己辩护行不行""调解书有法律效力吗""强制执行怎么申请""被列入失信名单怎么办""被当成老赖怎么办""对方转移财产怎么办""判决后不执行怎么办""取保候审要什么条件""能不能不起诉"等。也覆盖律师、法务的高频专业任务：按案号查案例、按裁判要旨找类案、法条沿革追溯、法条效力核实、合同条款分析与漏洞审查、违约赔偿计算、劳动关系认定、竞业限制审查、裁判口径对比与各地裁判标准差异分析、合规审查、诉讼风险评估、仲裁策略设计、调解方案拟订、强制执行与财产保全分析、刑事报案可行性初评、证据链梳理、庭审准备提纲、再审申请、执行异议、破产债权申报等。用户上传合同、判决书、起诉状、答辩状、仲裁申请书、执行申请书、律师函等法律文件时自动触发分析，支持多轮追问与策略细化。不适用于出具正式法律意见书、代写法律文书、代理出庭、学术写作或非中文法律检索。

## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
