# Platform Guides / 平台指南

## What this is

寻数平台操作与制作指南：①壹座与萬星使用手册——AI 助手工作台怎么用、功能集怎么装、Agent 服务怎么部署与调用（A2A）；②谦面功能集制作的**编排补篇**——批量套件的定义 schema、registry 侧技能注册、权限与计费四道闸全貌。（**想自己做一个功能集，请装《谦面工坊》**：它带发现与发布工具、覆盖完整创作流程；本包的制作技能只讲工坊不覆盖的平台内部细节。）平台官方维护，随平台演进更新。

Operation and authoring guides for the Finddata platform: 1) the Yizuo and Wanxing manuals — using the AI assistant workbench, installing packs, deploying and calling agent services (A2A); 2) an orchestration supplement to Facet pack authoring — the batch-suite definition schema, registry-side skill registration, and the full picture of the four gates for permissions and billing. To author a pack yourself, install Facet Forge: it covers the whole creation flow; this pack's skills only cover platform internals the Forge does not. Maintained by the platform, updated as it evolves.
