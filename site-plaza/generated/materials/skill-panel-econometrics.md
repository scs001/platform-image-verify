# panel-econometrics

## What this is

面板数据计量分析。当用户要在"个体 × 时间"二维结构上做推断时使用——固定效应/随机效应与 Hausman 检验、聚类稳健标准误、动态面板（滞后因变量）、双重差分 DID 与平行趋势/事件研究检验、断点回归概念。面板取自柏讯服务端三类源：GTA 上市公司（firm-year）、中国城市（city-year）、世界银行 WDI（country-year），宏观控制变量取柏讯宏观序列。不涉及股价与市值建模。
